I have updated some logic for the Monopoly game project.

Parts that have been added:
- Jail mechanisms.
- Win and bankruptcy conditions

Parts that have not been implemented:
- Community Chest and Chance tiles
- Trading mechanisms

The code includes a playable terminal-based game for testing and debugging that can be removed later.

▶️ How to Run
1. Download the CMake Tools extension in VS Code.
2. Run the commands in `CMakeCommand.txt` from logic folder reference.
